SHA-256 checksums for the verifiable-core files.

Verify your download matches (run in this folder):

  # Linux / macOS
  shasum -a 256 -c CHECKSUMS.txt

  # or check one file directly, on any OS
  python -c "import hashlib;print(hashlib.sha256(open('verify.html','rb').read()).hexdigest())"

A matching checksum proves the file was not altered in transit or storage. It
does NOT, by itself, prove the file is honest, since whoever publishes a file
can publish a matching checksum for it. The checks that need no trust in the
publisher are the built-in Self-test (derivation matches the external BIP84
specification vector) and the air-gap test (run offline and it still works, so
it sends nothing). See README.md.
