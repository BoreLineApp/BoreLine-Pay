BoreLine Address Verifier

Independent proof that every invoice address BoreLine issued for you derives from your own key. This tool re-derives each address in your browser and flags any that does not match. It never sends your key anywhere, needs no private key, and cannot move funds. Because the key comes from you and this file comes from the public repo, a compromised server cannot pass the check by lying.

Remember stores your zpub and token in this browser only. Do not use it on a shared or public computer. If a device is lost, revoke the token from your dashboard.

Live monitoring, optional

Monitoring runs only while this tab stays open. For always on, unattended checks even after you close the browser, use the command line script with its watch mode. Auto report freezes the account without asking first, so turn it on only if you understand that a wrong or previous zpub will also trip it.

Self-test derives the published BIP84 specification vector and checks it against the known addresses. If it passes, this file's derivation is honest, independently of BoreLine. To prove it sends nothing, turn off your network and use offline mode: it still works, because all maths is local.

Advanced: verify offline (paste a feed instead of fetching)

On an air-gapped machine, fetch the feed elsewhere with curl -H "X-Verify-Token: TOKEN" API/api/merchant/verify-feed, paste the JSON here, and press Verify offline. Nothing leaves this page.

Confirm payments on chain (optional)

Go past checking addresses: reconcile what the blockchain actually shows against what BoreLine reports. Catches a "paid" we claim with no on-chain funds, or a payment you received that we did not surface. Needs your zpub and token above, plus a chain source.

Public explorers: https://mempool.space or https://blockstream.info. Your own node: the URL of your self-hosted mempool or Esplora instance, which is the private choice since the source sees which addresses you look up. For a bare Bitcoin Core or Electrum server, use the command-line script instead.

If set, every address is checked against both sources and any disagreement is flagged, so one dishonest or lagging explorer is not enough to mislead you. Leave blank to skip.

How it works. BIP84 derivation is deterministic: one zpub plus one index gives exactly one address. For each invoice the server tells us only the derivation index and the address it issued. This page derives m/0/index from your zpub and confirms they match. All maths runs locally with no dependencies.

Why your key stays here. If the checker got your key from the server, the server would control both sides and could hand over a matching fake. Your key comes from you, so it cannot.

Get the token. In your dashboard, open the Verify page and generate a verification token. It is a dedicated, revocable credential that unlocks only your address feed, nothing else, so it cannot read customer data, move funds, or change settings. It is separate from any phone you have paired.
